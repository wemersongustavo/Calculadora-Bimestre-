
# Sistema de Acompanhamento Acadêmico

## Sobre o projeto

Sistema de Acompanhamento Acadêmico desenvolvido com HTML, CSS e JavaScript. Permite cadastrar o nome do aluno, inserir quatro notas, calcular a média final e verificar a situação acadêmica, considerando a média mínima de 7,0 para aprovação. O projeto também conta com layout responsivo e animações de interação.

## Funcionalidades

- Cadastro do nome do aluno.
- Inserção de quatro notas de avaliação.
- Validação das notas, aceitando valores entre 0 e 10.
- Cálculo automático da média final.
- Verificação da situação acadêmica do aluno.
- Mensagens personalizadas para aprovação, aprovação na média ou reprovação.
- Interface responsiva para diferentes tamanhos de tela.
- Animações de interação no botão de cálculo.

## Tecnologias utilizadas

- HTML5 — estrutura da página.
- CSS3 — estilização, layout responsivo e animações.
- JavaScript — validação dos dados, cálculo da média e exibição dos resultados.

## Média para aprovação

A média mínima para aprovação é **7,0**.

- Média acima de 7,0: aluno aprovado.
- Média igual a 7,0: aluno aprovado na média.
- Média abaixo de 7,0: aluno não aprovado.

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Digite o nome do aluno e preencha as quatro notas.
5. Clique em **Calcular Média** para visualizar o resultado.

## Objetivo

O projeto tem como objetivo praticar os conhecimentos de HTML, CSS e JavaScript por meio do desenvolvimento de um sistema simples de acompanhamento do desempenho escolar.
